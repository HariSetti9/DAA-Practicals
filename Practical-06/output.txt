MATRIX CHAIN MULTIPLICATION USING DYNAMIC PROGRAMMING
-----------------------------------------------------
Dimension array p = {4, 10, 3, 8}

A1 = 4 x 10
A2 = 10 x 3
A3 = 3 x 8

STEP-BY-STEP DP CALCULATION

Chain length = 2

Finding m[1][2] for A1...A2:
  k = 1: m[1][1] + m[2][2] + p[0]*p[1]*p[2]
         = 0 + 0 + 4*10*3
         = 0 + 0 + 120 = 120
         -> New minimum; set m[1][2] = 120 and k[1][2] = 1

Finding m[2][3] for A2...A3:
  k = 2: m[2][2] + m[3][3] + p[1]*p[2]*p[3]
         = 0 + 0 + 10*3*8
         = 0 + 0 + 240 = 240
         -> New minimum; set m[2][3] = 240 and k[2][3] = 2

Chain length = 3

Finding m[1][3] for A1...A3:
  k = 1: m[1][1] + m[2][3] + p[0]*p[1]*p[3]
         = 0 + 240 + 4*10*8
         = 0 + 240 + 320 = 560
         -> New minimum; set m[1][3] = 560 and k[1][3] = 1
  k = 2: m[1][2] + m[3][3] + p[0]*p[2]*p[3]
         = 120 + 0 + 4*3*8
         = 120 + 0 + 96 = 216
         -> New minimum; set m[1][3] = 216 and k[1][3] = 2

M TABLE (minimum scalar multiplications)
i\j     1         2         3
1       0         120       216
2       -         0         240
3       -         -         0

K TABLE (best split position)
i\j     1         2         3
1       -         1         2
2       -         -         2
3       -         -         -

HOW THE BRACKETS ARE FORMED
k[1][3] = 2, so split A1...A3 after A2.
Left part A1...A2 becomes (A1 x A2).
Right part A3...A3 becomes A3.
Combine both parts: ((A1 x A2) x A3)

OPTIMAL MULTIPLICATION ORDER
Step 1: (A1 x A2) = (4 x 10) x (10 x 3)
        Result dimension = 4 x 3
        Scalar multiplications = 4*10*3 = 120
Step 2: ((A1 x A2) x A3) = (4 x 3) x (3 x 8)
        Result dimension = 4 x 8
        Scalar multiplications = 4*3*8 = 96
Total = 120 + 96 = 216

FINAL ANSWER
Optimal parenthesization: ((A1 x A2) x A3)
Minimum scalar multiplications: 216
Time complexity: Theta(n^3)
Space complexity: Theta(n^2)
