# Practical 6 - Matrix Chain Multiplication using Dynamic Programming

**Course:** DAA (01AI0506)  
**Name:** SETTI APPALANAIDU  
**Enrollment No:** 92510118026

This practical finds the minimum-cost parenthesization for a chain of matrices. The program prints:

- every candidate split and scalar-multiplication calculation;
- the completed `m` cost table;
- the completed `k` split table;
- recursive bracket reconstruction;
- the dimensions and cost of every multiplication in the optimal order.

Files:

- `practical_06.cpp` - C++ source code
- `output.txt` - complete program output
- `Practical_06.pdf` - practical report in lab-manual format

## Compile

```bash
g++ -std=c++17 practical_06.cpp -o practical_06
./practical_06
```
